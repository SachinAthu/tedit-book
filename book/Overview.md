# Project Overview

## Title

**Building a Terminal Text Editor**  
_From First Principles to Professional Architecture_

## Purpose

This repository contains the complete manuscript for **Building a Terminal Text Editor**, a technical book that teaches systems programming and software architecture by designing and implementing a terminal-based text editor from scratch.

The project follows a **theory-first** approach. Readers first learn the underlying concepts—terminal programming, operating systems, software architecture, rendering, data structures, and file systems—before implementing the editor.

## Target Audience

Developers with basic C programming knowledge who want to deepen their understanding of systems programming and software engineering.

## Technology

- Language: C (C99)
- Primary Platform: Linux (POSIX)
- Markdown for all manuscript files
- Git for version control

## Repository Structure

- `Book-Bible.md` — Writing standards and educational philosophy.
- `Outline.md` — Complete book outline.
- `ADRs.md` — Architecture Decision Records.
- `GLOSSARY.md` — Canonical project terminology.
- `REVIEW_GUIDELINES.md` — Editorial review process.
- `volume-*` — Book chapters organized by volume.
- `appendices/` — Reference material and supporting content.

## Guiding Principles

- Explain concepts before implementation.
- Prioritize understanding over memorization.
- Keep terminology consistent throughout the book.
- Make every design decision explicit and justified.
- Produce a publication-quality technical manuscript.
